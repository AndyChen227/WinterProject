# 02 · C 进阶

时间：寒假第 1 周
完成标准：能用指针写一个单链表（增删查）；能用位运算设置、清除、翻转、读取某一位

这一部分是嵌入式面试的重点，几乎必考。

## 知识点

### 指针
- [ ] 地址、`&` 和 `*`
- [ ] 指针与数组的关系，指针运算
- [ ] 指针作为函数参数（实现“传引用”，例如 `swap`）
- [ ] 指向指针的指针
- [ ] 函数指针、回调函数
- [ ] `const` 与指针的几种组合（`const int *p` / `int *const p`）
- [ ] 野指针、空指针、悬空指针

### 内存
- [ ] 内存分区：栈、堆、全局/静态区、代码区
- [ ] `malloc` / `calloc` / `free`，内存泄漏
- [ ] `sizeof` 与结构体对齐（padding）

### 结构体与其他类型
- [ ] `struct`、结构体指针、`->`
- [ ] `typedef`
- [ ] `union`、`enum`
- [ ] 位域（bit field）

### 位运算
- [ ] `&` `|` `^` `~` `<<` `>>`
- [ ] 置位 / 清零 / 翻转 / 读取某一位
- [ ] 掩码（mask）
- [ ] 大端与小端

### 关键字与预处理
- [ ] `volatile`：为什么中断里共享的变量要加
- [ ] `static` 用在函数和全局变量上的含义
- [ ] `extern`
- [ ] 宏函数与它的坑（括号、副作用）
- [ ] 条件编译 `#if` / `#ifdef`

## 练习建议

单链表、动态数组、用结构体存学生信息并排序、用位运算模拟一个 8 位寄存器的配置。
