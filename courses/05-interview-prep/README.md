## 🧠 问题清单

### 🔤 C 语言
- [ ] `volatile`、`static`、`const`、`extern` 的作用
- [ ] 指针和数组的区别
- [ ] 内存分区，栈和堆的区别
- [ ] 结构体对齐怎么算
- [ ] 大小端怎么判断
- [ ] 宏和内联函数的区别

### 🔌 嵌入式
- [ ] 中断的处理流程，中断里不能做什么
- [ ] UART / I2C / SPI 的区别和时序
- [ ] DMA 是什么，什么时候用
- [ ] 看门狗
- [ ] 裸机和 RTOS 的区别
- [ ] 任务调度、优先级反转
- [ ] PWM 原理，电机怎么调速和换向
- [ ] I2S 音频：采样率、位深
- [ ] ADC 的分辨率和采样率

### 📐 专业课
- [ ] 模电：运放、二极管、三极管/MOSFET 基本电路
- [ ] 数电：组合逻辑、触发器、状态机
- [ ] 传输线、特征阻抗、S 参数、Smith 圆图（对应 Fu Lab 的 PCB）

### 🐱 项目讲解
- [ ] Fu Lab 微波 PCB：做什么、为什么这么设计、遇到什么问题
- [ ] AI 宠物小车：系统框图、各任务怎么分、延迟怎么优化、遇到的难点
- [ ] 1 分钟中文自我介绍
