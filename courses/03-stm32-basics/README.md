# 03 · STM32 入门

时间：寒假第 2–3 周
硬件：STM32 Nucleo-F446RE
工具：STM32CubeIDE + HAL 库
完成标准：机械臂的 4 个舵机能用 PWM 平稳控制，电脑能通过串口发指令

## 知识点

### 开发环境
- [ ] 安装 STM32CubeIDE，新建工程，用 CubeMX 配置引脚
- [ ] 编译、烧录、单步调试（断点、看变量）
- [ ] 读懂一个 HAL 工程的结构：`main.c`、`stm32f4xx_it.c`、`Core/` `Drivers/`

### 外设
- [ ] GPIO：点亮 LED、读按键
- [ ] 时钟树：系统时钟怎么来的
- [ ] 外部中断（EXTI）：按键中断
- [ ] UART：`printf` 重定向到串口，中断接收
- [ ] 定时器：定时中断、PWM 输出（舵机 50 Hz，脉宽 0.5–2.5 ms）
- [ ] ADC：读电位器电压
- [ ] I2C：读一个传感器或驱动 OLED
- [ ] DMA：串口 DMA 接收
- [ ] Flash：掉电保存数据

### 概念
- [ ] 寄存器 vs HAL 库：至少用寄存器方式点一次灯
- [ ] 中断优先级（NVIC）
- [ ] 轮询、中断、DMA 三种方式的区别

## 练习建议

每个外设在 `code/` 下建一个小工程或放核心代码片段，笔记里记录 CubeMX 的配置截图和参数。
