# 01 · C 入门

时间：2026.11 – 2026.12 中，期末期间每天约 1 小时
课程：翁恺《C 语言程序设计》（B 站 / 中国大学 MOOC）或 Harvard CS50 前几周
完成标准：不看答案能独立写出 20 道简单题

## 知识点

### 环境
- [ ] 安装编译器（gcc / clang），在命令行编译运行 `hello.c`
- [ ] 理解编译 → 链接 → 运行的过程

### 基础语法
- [ ] 变量与数据类型：`int` `char` `float` `double`，各占多少字节（`sizeof`）
- [ ] 常量、`#define`
- [ ] 输入输出：`printf` / `scanf` 与格式符
- [ ] 运算符：算术、关系、逻辑、自增自减，优先级

### 流程控制
- [ ] `if` / `else`、`switch`
- [ ] `for` / `while` / `do-while`
- [ ] `break` / `continue`

### 函数
- [ ] 定义、声明、调用、返回值
- [ ] 形参与实参（值传递）
- [ ] 局部变量、全局变量、`static`
- [ ] 递归

### 数组与字符串
- [ ] 一维数组、二维数组
- [ ] 数组作为函数参数
- [ ] 字符数组与字符串、`'\0'`
- [ ] 常用字符串函数：`strlen` `strcpy` `strcmp` `strcat`

### 多文件
- [ ] 头文件 `.h` 与源文件 `.c` 的分工
- [ ] `#include` 与头文件保护（`#ifndef`）

## 练习建议

每个知识点写 2–3 个小程序放到 `code/`，例如：温度换算、判断素数、冒泡排序、数组求最大值、字符串反转、九九乘法表。
