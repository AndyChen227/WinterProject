# 🍊 小橙 Cora · 屏幕看板娘

住在小车 3.5 寸屏幕里的 AI 助手。平时趴在屏幕下边缘偷偷看你，嘴上傲娇，其实一直在等你回来。

| | |
|---|---|
| 性格 | 呆萌、傲娇、嘴硬心软，会监督你学习 |
| 造型 | 2 头身 · 圆圆的包子脸 · 橙色长发 + 卷卷呆毛 · 星星发卡 · 珊瑚橙蝴蝶结 · 奶白泡泡袖 + 藏青背带裙 |
| 配色 | 🟠 `#F0814E` 发色　🟧 `#EE7A55` 珊瑚橙　🔵 `#3E4466` 藏青　⚪ `#FFFBF4` 奶白　🟡 `#F4B544` 金色点缀 |

## 📁 文件

- [`cora.svg`](cora.svg)：矢量原图，放大缩小都清楚
- [`cora.png`](cora.png)：1200×1200 位图
- [`src/draw_cora.py`](src/draw_cora.py)：生成 `cora.svg` 的脚本，运行 `python3 src/draw_cora.py`

> 原创角色，全部用代码绘制。屏幕上的表情和动画等主功能做完再加。
