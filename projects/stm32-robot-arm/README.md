# STM32 Robot Arm

基于 STM32 + FreeRTOS 的 4 自由度桌面机械臂。项目尚未开始，下面是计划。

## 目标功能

- [ ] L1 基础控制：定时器 PWM 驱动 4 个舵机，角度限位，平滑加减速
- [ ] L2 指令控制：自定义串口/蓝牙协议（帧头 + 校验），电脑或手机控制
- [ ] L3 示教回放：电位器示教，动作存入 Flash，断电后可回放
- [ ] L4 FreeRTOS：通信、运动规划、传感器多任务，队列传指令
- [ ] L5 逆运动学：输入 (x, y, z) 坐标，自动计算关节角度并直线插值
- [ ] L6 可选：电流检测判断是否夹住物体 / 摄像头识别颜色方块

## 硬件

| 部件 | 用途 |
| --- | --- |
| STM32 Nucleo-F446RE | 主控 |
| 4 自由度机械臂套件（MG90S / MG996R 舵机 + 夹爪） | 机械结构 |
| 5–6 V / 5 A 电源 | 舵机独立供电 |
| 电位器 ×4 或摇杆 | 示教输入 |
| HC-05 蓝牙模块 | 无线控制 |
| INA219 电流传感器（可选） | 夹取检测 |
